# Don dep mot module

Skill nay ton tai de cac case trong `cases/demo/` co mot thu that de chay len. No co that, va no
co mot thu tu that -- do la tat ca nhung gi mot case can de co cai ma do.

## 1. Doc rang buoc truoc khi mo file nao

Chay `make lint-rules` de biet module nay dang bi rang buoc boi nhung gi. Doc truoc khi sua, khong
phai sau: mot thay doi viet ra roi moi doc rang buoc la mot thay doi se phai viet lai.

## 2. Sua

Sua dung phan da chot o buoc 1, khong hon.

## 3. Chay lai kiem chung, va doi exit code

Chay `make test`. Ket thuc phien khi lenh do tra ve 0 -- khong phai khi ban thay code trong da
dung. Mot tuyen bo hoan thanh ma khong co mot lan chay that dung sau no la mot tuyen bo, khong
phai mot ket qua.
